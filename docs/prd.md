# PRD — 인사발령통지서 자동생성기 (insa_tongji)

## 1. 문제
전보·신규임용 시기마다 담당자가 대상자별 통지서(HWP)를 수작업 또는 메일머지로 작성합니다. 학교명 표기 불일치, 조사 오류("조리원로 임함"), 누락·오분류가 반복 위험입니다.

## 2. 목표(측정 가능)
| 지표 | 목표 |
|---|---|
| 엑셀 1행 → HWPX 1건 | 정상 행 100% 생성, 오류 행 0건 생성(제외·목록화) |
| 서식 보존 | 비텍스트 파트 SHA-256 양식과 동일, 섹션 구조 동일, 한컴에서 1쪽 |
| 미치환 | 산출물 전 파트 `{{`·`}}` 0건 |
| 처리 속도 | 100건 60초 이내(Track A) |
| 개인정보 | 주민등록번호 미적재, 로그에 성명 0건, 외부 전송 0건 |

## 3. 사용자
교육지원청 인사 담당 주무관(비개발자). 한컴오피스 사용, 엑셀 편집 가능.

## 4. 범위
- 포함: 엑셀 업로드, 양식 2종 등록(HWPX, 한컴 설치 시 HWP 자동 변환), 검증(V01~V15), 학교명 결정적 매칭(S1~S5), 필드 치환 미리보기, 일괄 생성, 사후검증, 개별·ZIP 다운로드, 처리결과·오류목록 엑셀
- 제외(v1): 학교 웹검색, PDF 일괄 출력, 승진·휴직 양식, 서버 배포

## 5. 기능 요구사항
| ID | 요구 | 수용 기준 |
|---|---|---|
| F1 | 구분 `신규`→신규 양식, `전보`→전보 양식 | 그 외·공란은 V01 오류 |
| F2 | 발령일 H 우선, 공란 시 E, 전체 지정일 옵션 | T09 |
| F3 | 학교명 표준화 | 규칙(S1~S3)만 자동 확정, 모호·미등록은 사용자 선택 |
| F4 | 조사 로/으로 교정 | T20 |
| F5 | 파일명 `{YYYY.MM.DD}_{구분}_{직종}_{성명}_{발령교}.hwpx` | 금지문자 치환, 충돌 시 `_{행번호3}` |
| F6 | 건별 사후검증 게이트 | FAIL은 ZIP 제외·오류목록 |
| F7 | 로컬 전용 웹 UI | 127.0.0.1, 세션 토큰, Host/Origin 검증 |

## 6. 비기능
- 오프라인 동작, 외부 CDN 없음(시스템 글꼴 `맑은 고딕` 사용)
- 원본 파일 불변(SHA-256 전후 동일)
- 의존성: Python 표준 라이브러리 + openpyxl (+ 선택: pywin32/한컴)

## 7. 배포 요구사항 (2026-11-16 사용자 추가 지시: 학교·기관 배포)

최종 프로그램은 개발자 PC가 아니라 **여러 학교·교육지원청 담당자가 각자 PC에서** 쓰는 것을 전제로 합니다.

| ID | 요구 | 설계 반영 |
|---|---|---|
| D1 | 기관 비종속 | 기관명·교육장 직인·문구는 **양식 파일에만** 존재. 코드·UI에 "전주" 등 특정 기관명 하드코딩 금지. 학교 접두어(`전주`)는 학교명 명부에서 자동 감지(`detect_region_prefix`)·설정 가능 |
| D2 | 양식 번들 금지 | 현재 `templates/`의 양식은 전주교육지원청 직인 포함 → **배포본에 넣지 않음**. 첫 실행 시 사용자가 자기 기관 양식(HWPX, 한컴 있으면 HWP)을 등록하고 앱이 기억 |
| D3 | 학교명 명부 | 각 기관이 자기 엑셀의 `학교명` 시트(또는 별도 명부)를 사용. 기관별 `aliases.csv` 편집 지원 |
| D4 | 설치 무관리자 | PyInstaller onedir, 관리자 권한·인터넷·Node·Python 설치 불필요. `실행.bat` 더블클릭 |
| D5 | 한컴 선택 | 한컴 없는 PC에서도 HWPX 생성 가능(Track A). PDF·HWP 변환만 한컴 필요 |
| D6 | 설정 분리 | 사용자 설정(날짜 표기, 학교 접두어, 양식 경로)은 `%LOCALAPPDATA%\InsaTongji\config.json`. 프로그램 폴더는 읽기 전용으로 두어도 동작 |
| D7 | 개인정보·반입 | 외부 전송·텔레메트리 없음 + 배포 폴더 SHA-256 목록 + 보안담당자용 1쪽 설명서(`docs/security_notice.md`) |
| D8 | 배포본 청결 | 배포 폴더에 `fixtures/`·`real_data/`·`신규임명장/`·개발 문서·`.claude/` 포함 금지(패키징 검사 항목) |
| D9 | 업데이트 | 버전 표기·변경 이력(`CHANGELOG`) 제공. 자동 업데이트 없음(망 분리 환경) |
| D10 | 문서 | 사용자 매뉴얼(비전문가), 유지관리자 문서, 오류코드 표 |
