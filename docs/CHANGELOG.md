## 1.0.1 (2026-11-16)
- 결과물 이름 규칙: `인사발령장 자동생성기-YYYYMMDD-vX.Y.Z`(폴더·ZIP·SHA-256 파일), 제품명 "인사발령장 자동생성기"로 통일, 화면 하단에 버전 표시
- 초기화 버튼: 불러온 엑셀·수정·생성 결과 삭제(등록한 양식은 선택 삭제)
- 화면 개선: 현황 대시보드(KPI·구분/검증 상태 도넛·직종/발령교/검증 항목 막대·생성 결과 게이지), 반투명 카드·푸른 계열 디자인, 단계 표시 바
- 새로고침 시 불러온 자료·생성 결과 복원, 표 줄바꿈 개선

## 1.0.0 (2026-11-16)
- 최초 릴리스: 신규 임용장·전보 인사발령통지서 HWPX 일괄 생성
- 엑셀 검증(V01~V15), 학교명 규칙 매칭(공식명·별칭·유일 약칭만 자동 확정, 유사명은 제안만)
- 발령일 기준 선택(발령일→임용일 / 임용일→발령일 / 전체 동일), 날짜 표기 2종
- 직종 뒤 "로/으로" 자동 교정
- 생성 파일별 사후검증(ZIP·미치환·기대값·비텍스트 파트 해시·본문 구조)
- 로컬 전용 웹 화면(127.0.0.1, 세션 토큰), 외부 통신 없음
- 기관별 양식 등록·기억, 학교 명부·별칭표 로컬 저장
