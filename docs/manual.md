# 인사발령장 자동생성기 사용설명서

신규 임용장과 일반 전보 인사발령통지서를 엑셀 한 장에서 일괄로 만듭니다. 이 PC 안에서만 동작하며 인터넷으로 자료를 보내지 않습니다.

## 0. 초기화
화면 오른쪽 위 `초기화` 버튼은 불러온 엑셀·수정 내용·생성 결과를 모두 지우고 처음 상태로 돌립니다. "등록해 둔 양식도 함께 삭제"를 체크하면 양식도 지웁니다. 이미 내려받은 파일은 지워지지 않습니다.

## 1. 시작하기
1. 받은 폴더(`insa_tongji`)를 PC의 원하는 곳에 **압축을 풀어 통째로** 둡니다. 관리자 권한·설치가 필요 없습니다.
2. `실행.bat`을 더블클릭합니다. 검은 창이 열리고 잠시 뒤 브라우저에 프로그램 화면이 나타납니다.
3. 작업이 끝나면 검은 창을 닫으면 프로그램이 종료됩니다.

> 브라우저에 화면이 나오지 않으면 검은 창에 표시된 주소(`http://127.0.0.1:…`)가 아니라, **프로그램이 자동으로 연 창**을 사용하세요. 주소에 보안 코드가 포함되어 있어 코드 없이 접속하면 막힙니다.

## 2. 준비물
| 준비물 | 설명 |
|---|---|
| 인사발령 엑셀 | `인사발령` 시트(1행 제목: 순·직종·성명·주민등록번호·임용일·현임교·발령교·발령일·구분)와 `학교명` 시트(학교 명부)가 있는 파일 |
| 신규 양식 | 기관의 임용장 양식 `.hwpx` (한컴오피스가 있으면 `.hwp`도 가능) |
| 전보 양식 | 기관의 전보 인사발령통지서 양식 `.hwpx` |

양식 안에는 값이 들어갈 자리에 `{{직종}}` `{{성명}}` `{{발령일}}` `{{현임교}}` `{{발령교}}`를 적어 둡니다. 신규 양식에는 `{{현임교}}`가 없어도 됩니다.

## 3. 사용 순서
**① 자료** — 엑셀을 끌어다 놓습니다. 위쪽 숫자에서 전체·신규·전보·정상·확인 필요 인원을 봅니다. 주민등록번호 열은 읽어 쓰지 않습니다.
- 발령일 기준: 기본은 `발령일` 열 → 비어 있으면 `임용일`. 전체를 같은 날짜로 하려면 "전체 동일 일자 지정"
- 날짜 표기: `2026년 11월 1일` 또는 `2026. 11. 1.`

**② 양식** — 신규·전보 양식을 한 번 등록하면 이 PC에 기억됩니다. 양식이 바뀌면 다시 등록하세요.

**③ 검증·수정** — 표에서 문제 있는 행(붉은 배경)을 고칩니다. 칸을 직접 수정할 수 있습니다.
- 학교명이 모호하거나 없으면 후보 목록에서 고르거나 공식 학교명을 직접 입력하고 `적용`을 누릅니다. "별칭 저장"을 체크하면 다음부터 자동으로 인식합니다.
- 자동으로 학교명을 확정하는 것은 규칙이 분명한 경우뿐입니다(공식명 일치, 별칭표, 유일한 약칭). 비슷한 이름은 **추천만** 하고 사람이 고릅니다.

**④ 생성** — 범위(전체/신규만/전보만/선택)를 고르고 `통지서 생성`. 오류가 있는 대상자는 자동으로 빠지고 나머지는 계속 만들어집니다.

**⑤ 결과 확인·다운로드·출력** — 생성된 문서 목록에서 대상자를 고르면 화면에서 실제 모양(PDF)을 볼 수 있고, 괜찮으면 `이 파일 다운로드` 또는 `출력`을 누릅니다. 화면 보기·출력은 한컴오피스가 설치된 PC에서만 되며, 없으면 HWPX를 내려받아 한컴에서 여세요. `전체 ZIP 저장`(신규·전보 폴더 + 처리결과.xlsx + 오류목록.xlsx)과 오류 목록 저장도 이 단계에서 합니다.

## 4. 파일 이름
`2026.11.01_신규_조리실무사_홍길동_전주하가초등학교.hwpx` 형식입니다. 같은 이름이 있거나 동명이인이면 `_행번호`가 붙습니다.

## 5. 오류·경고 코드
| 코드 | 뜻 | 조치 |
|---|---|---|
| V01 | 구분이 신규/전보가 아님 | 엑셀의 구분 열 수정 |
| V02 | 직종·성명·발령교 빈 값 | 값 입력 |
| V03 | 전보인데 현임교 없음 | 현임교 입력 |
| V04(경고) | 신규인데 현임교가 있음 | 무시되어 생성됨 |
| V05(경고) | 현임교와 발령교가 같음 | 확인 |
| V06 | 발령일·임용일 모두 날짜로 읽을 수 없음 | 날짜 수정 |
| V07(경고) | 발령일≠임용일, 또는 한쪽을 읽지 못해 다른 쪽을 씀 | 사용된 날짜 확인 |
| V08(경고) | 발령일이 오늘 기준 1년 밖 | 날짜 확인 |
| V09(경고) | 같은 내용의 행이 중복 | 중복 행 확인 |
| V10(정보) | 동명이인 | 파일명에 행 번호 부여 |
| V11 | 학교명을 확정하지 못함 | 후보 선택 또는 직접 입력 |
| V12(경고) | 직종 끝글자가 한글이 아니라 "로/으로" 교정 불가 | 확인 |
| V13(경고) | 성명·학교명이 길어 줄바꿈 영향 가능 | 한컴에서 확인 |
| V14 | 값에 `{{` 또는 `}}` 포함 | 값 수정 |
| V15 | 양식이 요구하는 값이 없음 | 값 입력 |

처리결과의 `조사교정`은 직종 뒤 "로"를 "으로"로 바꾼 건입니다(예: 조리원 → 조리원**으로** 임함).

## 6. 자주 묻는 질문
- **한컴오피스가 없는 PC에서도 되나요?** 네. HWPX 양식으로 생성할 수 있습니다. `.hwp` 양식 등록과 PDF 변환만 한컴이 필요합니다.
- **생성된 파일이 많아 용량이 큰가요?** 직인 이미지가 포함되어 한 건에 약 0.5~1MB입니다. 100건이면 수십~백 MB가 될 수 있습니다.
- **학교가 신설·폐교되면?** 엑셀의 `학교명` 시트를 고쳐서 다시 불러옵니다. `학교명` 시트가 없는 엑셀을 불러오면 마지막으로 저장된 명부를 씁니다.
- **내 PC 어디에 무엇이 저장되나요?** `%LOCALAPPDATA%\InsaTongji`에 설정(config.json), 등록한 양식(templates), 학교 명부(schools.txt), 별칭표(aliases.csv)만 저장됩니다. 엑셀 내용과 생성된 통지서는 저장되지 않습니다(메모리에서만 처리, 다운로드한 것만 남음).
