# 보안담당자용 안내 (1쪽)

**프로그램**: 인사발령장 자동생성기 (insa_tongji) — 신규 임용장·전보 인사발령통지서 HWPX 일괄 생성
**형태**: Windows 폴더 배포(`insa_tongji.exe` + `_internal`), 설치·관리자 권한 불필요

## 데이터 처리
| 항목 | 내용 |
|---|---|
| 처리 위치 | 사용자 PC의 메모리. 서버·클라우드 없음 |
| 외부 통신 | **없음**. 소스에 외부 호출·텔레메트리·업데이트 확인 코드가 없고, 웹 화면도 외부 CDN·글꼴을 쓰지 않음 |
| 로컬 서버 | `127.0.0.1`만 바인딩(다른 PC에서 접속 불가), 실행마다 임의 포트와 세션 토큰 생성 |
| 접근 통제 | 모든 요청에 세션 토큰 필요, `Host`·`Origin` 검증, CORS 허용 헤더 없음(다른 웹사이트가 호출 불가), 보안 응답 헤더·CSP 적용 |
| 주민등록번호 | **사용하지 않음**. 엑셀의 해당 열은 결과·로그·화면·산출물 어디에도 복사되지 않음(자동 테스트로 검증) |
| 로그 | 요청 로그를 남기지 않음. 성명·주민번호는 콘솔·파일에 출력되지 않음 |
| 저장되는 것 | `%LOCALAPPDATA%\InsaTongji`: 설정, 사용자가 등록한 양식, 학교 명부, 별칭표 |
| 저장되지 않는 것 | 엑셀 내용, 대상자 정보, 생성된 통지서(사용자가 내려받은 파일만 남음) |
| 임시 파일 | 한컴 변환(HWP→HWPX, PDF) 시에만 사용 후 삭제 |
| 원본 파일 | 읽기만 하고 수정하지 않음 |

## 한컴오피스 연동(선택)
한컴오피스가 설치된 PC에서만 `.hwp` 양식을 HWPX로 변환하고 PDF를 만드는 데 COM 자동화를 사용합니다. 없으면 이 기능만 꺼지고 HWPX 생성은 정상 동작합니다.

## 반입·검증
- 배포 폴더의 `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다.
- 백신이 PyInstaller 실행 파일을 오탐할 수 있습니다. 이 경우 보안담당자가 해시를 확인한 뒤 예외 등록하세요. (본 패키지는 서명되지 않았습니다)
- 배포본에는 개발용 자료(샘플·실자료·테스트)와 특정 기관 양식·직인이 **포함되지 않습니다**(배포 전 자동 검사).

## 알려진 한계
- 서명되지 않은 실행 파일입니다.
- 같은 PC의 다른 계정/프로세스가 이 PC 안의 loopback에 접속할 수는 있으나, 토큰 없이는 응답하지 않습니다.
