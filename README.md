# 인사발령장 자동생성기

신규 임용장과 일반 전보 인사발령통지서를 **엑셀 한 장에서 HWPX 파일로 일괄 생성**하는 Windows용 프로그램입니다.
설치 없이 폴더를 풀어 `실행.bat`만 누르면 되고, **모든 처리가 내 PC 안에서만** 이뤄집니다(인터넷으로 자료를 보내지 않습니다).

![Windows](https://img.shields.io/badge/Windows-10%2F11-0078D4) ![version](https://img.shields.io/badge/version-1.0.3-17324D) ![local only](https://img.shields.io/badge/외부%20전송-없음-16836A)

## 이런 일을 합니다

| 하던 방식 | 이 프로그램 |
|---|---|
| 대상자마다 한글 양식을 열어 직종·성명·학교·날짜를 일일이 입력 | 엑셀 1장 → 대상자 1명당 통지서 1개 자동 생성 |
| 신규·전보 양식을 사람이 구분 | 엑셀의 `구분`(신규/전보) 열로 양식 자동 선택 |
| 학교명 표기 오류(예: `전주하가초`) | `학교명` 시트 기준으로 정식 명칭(`전주하가초등학교`)으로 정규화 |
| 생성 후 눈으로 일일이 확인 | 오류 행 자동 제외, 생성 후 화면에서 확인·다운로드·출력 |

## 다운로드와 실행

1. **[Releases](../../releases/latest)** 에서 `insa-tongji-vX.Y.Z-win64.zip`을 받습니다.
2. ZIP을 **원하는 폴더에 통째로 압축 해제**합니다. (`exe`만 따로 복사하면 실행되지 않습니다. 설치·관리자 권한은 필요 없습니다.)
3. 폴더의 `실행.bat`을 더블클릭하면 브라우저에 프로그램 화면이 열립니다.
4. 작업이 끝나면 검은 창을 닫으면 종료됩니다.

> 처음 실행할 때 Windows SmartScreen이나 백신이 경고할 수 있습니다. 이 프로그램은 코드 서명이 없습니다. 릴리스에 적힌 **SHA-256 값**과 받은 ZIP의 해시가 같은지 확인한 뒤 실행하세요.
>
> ```powershell
> Get-FileHash .\insa-tongji-v1.0.3-win64.zip -Algorithm SHA256
> ```

## 준비물

이 저장소의 프로그램에는 **엑셀과 양식이 들어 있지 않습니다.** 기관에서 아래 두 가지를 준비해 화면에 올려 주세요.

### 1) 인사발령 엑셀
`인사발령` 시트의 **1행이 제목, 2행부터 대상자**입니다.

| 순 | 직종 | 성명 | 주민등록번호 | 임용일 | 현임교 | 발령교 | 발령일 | 구분 |
|---|---|---|---|---|---|---|---|---|

- `구분`은 `신규` 또는 `전보`만 허용합니다. 그 밖의 값은 오류로 표시됩니다.
- `발령일`이 비어 있으면 `임용일`을 씁니다. 전체를 같은 날짜로 지정할 수도 있습니다.
- `전보`는 `현임교`가 필수입니다.
- `주민등록번호` 열은 **읽지도, 저장하지도, 출력하지도 않습니다.**
- 같은 파일에 `학교명` 시트(학교 명부)가 있으면 학교명 정규화에 사용합니다.
- 형식을 보려면 [`fixtures/sample.xlsx`](fixtures/sample.xlsx)(가명 2건)를 참고하세요.

### 2) HWPX 양식 (신규용, 전보용 각 1개)
양식 안에서 값이 들어갈 자리에 아래 표시를 적어 둡니다.

`{{직종}}` `{{성명}}` `{{발령일}}` `{{현임교}}` `{{발령교}}`

- 신규 양식에는 `{{현임교}}`가 없어도 됩니다.
- 표·글상자 안에 있어도 치환됩니다. 양식의 글꼴·표·그림은 그대로 유지됩니다.
- `.hwpx`를 권장합니다. `.hwp`는 한컴오피스가 설치된 PC에서만 등록(자동 변환)할 수 있습니다.

## 사용 순서

1. **자료** — 엑셀을 끌어다 놓고 신규·전보·확인 필요 인원을 봅니다.
2. **양식** — 신규·전보 양식을 한 번 등록합니다. 이후 이 PC가 기억합니다.
3. **검증·수정** — 붉게 표시된 행을 고칩니다. 학교명이 모호하면 후보에서 고릅니다.
4. **생성** — 범위(전체/신규만/전보만/선택)를 고르고 `통지서 생성`.
5. **결과 확인·다운로드·출력** — 화면에서 확인한 뒤 개별 파일 또는 전체 ZIP(신규·전보 폴더, 처리결과.xlsx, 오류목록.xlsx)으로 저장합니다.

자세한 설명과 오류 코드(V01~V15)는 [사용설명서](docs/manual.md)를 보세요.

생성 파일 이름은 `2026.11.01_신규_조리실무사_홍길동_전주하가초등학교.hwpx` 형식이며, 같은 이름이 있으면 행 번호가 붙습니다.

## 한컴오피스가 필요한가요?

| 기능 | 한컴오피스 |
|---|---|
| HWPX 양식으로 통지서 생성·다운로드 | **불필요** |
| `.hwp` 양식 등록(자동 변환) | 필요 |
| 생성 결과 화면 보기(PDF)·출력 | 필요 |

## 개인정보와 보안

- 서버·클라우드가 없고 외부 통신 코드가 없습니다. 화면은 `127.0.0.1`(내 PC)에만 열립니다.
- 엑셀 내용과 생성된 통지서는 저장하지 않습니다. 내려받은 파일만 남습니다.
- `%LOCALAPPDATA%\InsaTongji`에는 설정, 등록한 양식, 학교 명부, 별칭표만 저장됩니다.
- 요청마다 세션 토큰과 `Host`·`Origin` 검증을 거쳐 다른 웹사이트가 호출할 수 없습니다.
- 보안 담당자용 상세 안내: [보안 안내](docs/security_notice.md)

> 실제 인사자료를 이 저장소에 올리지 마세요. 이슈나 풀 리퀘스트에도 성명·주민등록번호를 적지 마세요.

## 알려진 제한

- Windows 전용입니다.
- 한 건당 파일 크기가 직인 이미지 때문에 약 0.5~1MB입니다. 100건이면 수십~백 MB가 될 수 있습니다.
- 학교명은 규칙이 분명한 경우(정식명 일치, 별칭표, 유일한 약칭)만 자동 확정하고, 비슷한 이름은 추천만 합니다.
- 생성된 통지서는 **한컴오피스에서 열어 내용을 확인한 뒤** 사용하세요.

## 개발

Python 3.11 이상. 핵심 로직(`insa_tongji/core`)은 화면·한컴과 분리되어 있습니다.

```powershell
pip install openpyxl lxml pytest ruff        # 한컴 연동에는 pywin32 추가
python run_app.py                             # 소스로 실행
ruff check .                                  # 린트
python -m pytest -q                           # 테스트(한컴 불필요)
python -m pytest -m hancom -o addopts=""      # 한컴 연동 테스트(한컴 설치 PC)
pip install pyinstaller
python tools/build_dist.py                    # 배포 폴더·ZIP·SHA-256 생성(dist/)
```

```text
insa_tongji/core/   엑셀 읽기·검증·학교명 매칭·HWPX 치환·사후검증·패키징
insa_tongji/app/    로컬 웹 서버(127.0.0.1)와 화면
tests/              단위·통합·보안·한컴 연동 테스트
tools/              배포 빌드, 배포본 청결 검사, exe 스모크 테스트
docs/               사용설명서, 보안 안내, 유지관리자 문서, 변경 이력
```

변경 이력은 [CHANGELOG](docs/CHANGELOG.md)에 있습니다.
